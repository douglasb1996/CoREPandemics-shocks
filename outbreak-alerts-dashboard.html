About this dashboard

Built for corepandemicsandshocks.org. Data is fetched client-side from the public WHO API and refreshed on load.

For institutional use or embedding, host this single HTML file on your web server or static hosting (GitHub Pages, Netlify, Cloudflare Pages, etc.).

Disclaimer: This is not an official WHO or government product. Always consult primary sources (WHO, national health authorities) for decision-making. Automated aggregation may lag or omit events.
